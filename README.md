# Layout chợ trong nhà Noel – Tết · Helio

Trang chỉnh layout gian hàng trên mặt bằng tầng trệt Helio (Đà Nẵng).

- 1 gian chuẩn = 1,5 m ngang × 2 m sâu (bàn + chỗ đứng + ghế)
- Tỉ lệ bản vẽ theo mốc 7,06 m giữa 2 cột ở sảnh Balloon City (≈ 27,55 px/m)
- Kéo thả, xóa, xoay, đổi mặt tiền, thêm gian, đếm số gian, đo khoảng cách, kích thước dãy

## Mở trang
Mở `index.html` qua một web server (ví dụ GitHub Pages, hoặc `python3 -m http.server`).
Mở trực tiếp bằng file:// sẽ không tải được `layout_data.json`.

Ngoài claude.ai, trang lưu thay đổi trong trình duyệt (localStorage) và không có nút tải PNG.

## File
- `index.html` – trang chỉnh layout
- `base_plan.jpg` – mặt bằng nền
- `layout_data.json` – layout gốc (gian, luồng khách, mốc 7,06 m)
